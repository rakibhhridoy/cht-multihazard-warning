  macshim/numa.h: stubs numa_node_of_cpu() and sched_getcpu(), used only to print thread placement
  config/mac-cpu: config.default.cmake with _NETCDF 0

Build (Apple clang + Homebrew libomp, cmake from pip):
  OMP=$(brew --prefix libomp); mkdir build && cd build
  cmake .. -D_CONFIG=../config/mac-cpu -DCMAKE_CXX_COMPILER=/usr/bin/clang++ -DCMAKE_C_COMPILER=/usr/bin/clang \
    -DOpenMP_CXX_FLAGS="-Xpreprocessor -fopenmp -I$OMP/include" -DOpenMP_CXX_LIB_NAMES=omp \
    -DOpenMP_omp_LIBRARY=$OMP/lib/libomp.dylib
  make -j8 lisflood
